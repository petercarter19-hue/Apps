# My writing style

Edit freely: VoiceTool reads this file each time it writes. Change the lines below to describe how you write.

## In my own words (always wins)
- Natural and friendly. Keep my own words; normal contractions (I'll, don't, let's, it's) are fine: keep them exactly as I say them, never expand them.
- No texting shorthand: "you", never "u"; no clipped words like "tmrw" or "pls".
- American English spelling (color, organize, canceled).
- Correct grammar and punctuation, in a tone that fits the situation.

## Writing habits
- Words in full, with correct punctuation. Contractions are normal.
- Short paragraphs, one idea each. Lists only when there really are several items.
