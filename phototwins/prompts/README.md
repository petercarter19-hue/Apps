# The messages

Everything you type to the AI to build your duplicate photo finder, in order. Open a file, copy all of it, and paste it into your AI app. The [brackets] are your choices; [KIT.md](../KIT.md), section 4, explains each one.

1. **[kickoff.txt](kickoff.txt):** the one message that builds it, step by step. It answers every question up front, so the AI can just build.
   - Or **[kickoff-all-in-one-go.txt](kickoff-all-in-one-go.txt)** if you'd rather it build everything without stopping. Come back in about two hours.
2. **After each step:** try it, and if it works, say:

   ```text
   Works. Next step.
   ```

   If something's off, say what you did and what you saw. [KIT.md](../KIT.md), section 8, has ready-made messages for the problems we actually hit.
3. **Make it yours:** [KIT.md](../KIT.md), section 7, has messages for a different look, more photo types, a bigger or smaller card, and more.
4. **[friend-version.txt](friend-version.txt):** a clean copy you can give a friend, tested in Windows Sandbox first.
