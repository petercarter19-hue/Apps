# Status update

Have your AI report progress in one clear format every time. There are five parts:
- what's being worked on now;
- what's done;
- what's next;
- how long it will take;
- what it needs from you.

Every question is spelled out with a suggested answer, and the actual thing is shown: pictures, links and numbers.

It's made for anyone who isn't technical, or who checks in from a phone.

## Install
Copy this folder into your AI coding app's skills folder:
- Claude Code: `~/.claude/skills/status-update/`
- Codex: `~/.codex/skills/status-update/`
- Any other AI app that reads Agent Skills works too: put it wherever that app keeps skills.

## Try it
> Give me a status update.

> Where are we, and what's waiting on me?
